The base package includes local LP, MILP, QP, QUBO, HUBO, and Ising solvers. The public modelling and interoperability SDK is open source; the local solver runtime is distributed in binary-only form under Apache-2.0. Standard pip installation from PyPI selects the compatible wheel and installs its dependencies. Building a complete SDK wheel from the public source repository requires a compatible native binary. See Contributing for source development and documentation setup. Modelling, inspection, validation, conversion, and result evaluation remain credential-free. Local authentication does not create jobs or consume credits.

The quantum extra adds the pinned qpiai-quantum==0.3.0 integration; all includes it and OMMX. Local simulation and circuit execution use qpiai-quantum. Optional dependencies follow their own wheel availability.

Canonical IR uses schema version qpiai-opt-ir/1.0, independently of the package version.
